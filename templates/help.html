Support

Need a quick handoff?

Use this guide to get started with the camera, understand the supported vocabulary, and make the most of SignConnect.

01

Start translating

  1. Open the Translator page.
  2. Allow camera access when prompted.
  3. Hold a supported sign in front of the camera with a plain background.
  4. Wait for a stable prediction, then tap Add to Sentence or use the speech controls.
02

Supported signs

SignConnect currently supports a focused set of words:

bad call doctor emergency food good hello help i no please sorry stop thank-you water yes you
03

Improve accuracy

  • Keep your hand centered in the frame.
  • Use consistent lighting and a clean background.
  • Record signs on the Train page with multiple variations.
  • Use the model only for the project-defined vocabulary it has been trained on.
04

Accessibility

  • Use the keyboard to navigate and focus controls.
  • Use the theme toggle and high-contrast mode when needed.
  • Use browser speech synthesis for spoken output when supported.
  • All camera processing stays on this device.
